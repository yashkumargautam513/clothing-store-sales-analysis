# Clothing Store Sales Analysis 

This project is an Excel-based analysis of a clothing store's annual sales data. 
The goal was to explore the data, identify useful sales trends, and present the findings through an interactive dashboard.

## Files

- **Clothing Store Annual Dashboard.pdf** –  PDF preview containing a screenshot of the completed dashboard.
- **Clothing Store Annual Report.xlsx** – Original Excel dashboard and analysis.
- **Clothing Store Raw Data.xlsx** – Original dataset used for the analysis.

## Tools & Features

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Interactive Dashboard

## What the Dashboard Shows

The dashboard provides an overview of the store's annual sales performance and allows the data to be explored using different filters and visualizations.

It was created to make the sales data easier to understand and to practice turning raw data into a clear and interactive report.

## About the Project

This is a learning and practice project that I created while improving my Excel and data analysis skills.
